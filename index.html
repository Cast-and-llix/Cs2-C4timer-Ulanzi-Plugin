CS2 Bomb Timer Story

💣 CS2 Bomb Timer

for the Ulanzi D200 StreamDeck

A Ulanzi Studio plugin that turns one D200 key into a Counter-Strike 2 C4 timer. When the bomb is planted the key starts at 40 and counts down inside a shrinking ring.

CS2 starts it automatically through Game State Integration (GSI).

🏗️ Architecture

The data flows from Counter-Strike 2 through a lightweight Python server to the Ulanzi plugin and onto the physical key.

──GSI POST──▶
🐍 bomb_timer.py 127.0.0.1:3000
◀──GET /state──

──▶
⌨️ D200 Key 144×144 canvas

How the Backend Works

  • CS2 reports round.bomb = planted / defused / exploded to players, but not the countdown itself
  • The backend notes the moment of the plant and counts 40 s from there
  • If CS2 sends a countdown (spectating / GOTV), the backend re-syncs to it
  • If the timer reaches 0 and no exploded event arrives within 2.5 s, the bomb is assumed to have exploded
  • When the next round starts, the state goes back to idle

How the Plugin Works

  • Polls every 80 ms (~12×/s). A request times out after 400 ms; new ones never overlap
  • Between polls it interpolates the time left from the last value received
  • Key image is only re-sent when the signature changes (number, phase, or flash frame)
  • A whole round takes about 45 image updates
  • If no poll succeeds for 1.5 s → OFFLINE. One dropped poll doesn't trigger it
  • Worker-based timers.js so the hidden WebView doesn't slow them down

🛠️ Setup

1

CS2 GSI Config

Copy gamestate_integration_bomb.cfg into your CS2 cfg folder:

Windows: C:\Program Files (x86)\Steam\steamapps\common\
         Counter-Strike Global Offensive\game\csgo\cfg\

Restart CS2 — it only reads GSI files at startup. The file name must start with gamestate_integration_.

2

Backend

Python 3.8+. No packages needed.

python backend/bomb_timer.py            # basic
python backend/bomb_timer.py --voice    # + spoken callouts
OptionDefaultDescription
--port3000GSI POST + GET /state
--tokenCS2BOMBTIMERMust match .cfg; "" disables
--bomb-time40C4 fuse length (seconds)
--voiceoffpyttsx3 / macOS say / Win SAPI
3

Plugin

  1. Quit Ulanzi Studio completely
  2. Copy the whole com.ulanzi.cs2bombtimer.ulanziPlugin folder to:
    %APPDATA%\Ulanzi\UlanziDeck\Plugins\
  3. Start Ulanzi Studio. Drag CS2 Bomb Timer → Bomb Timer onto a key.
  4. The key shows C4 / READY. If it shows OFFLINE, check the backend.

Requires Ulanzi Studio 2.1.4+

📡 /state JSON Contract

Click any field to see its description.

"status""planted" idle | planted | defused | exploded
"time_remaining"23.418 Seconds (float) while planted, otherwise null
"seconds"24 ceil(time_remaining) — what the key shows
"phase""bomb" bomb | kit_only | too_late while planted, otherwise = status
"bomb_time"40 Total fuse time in seconds
"source""gsi" gsi | manual | null — where the countdown came from
"status_age"16.58 Seconds since status last changed — prevents stale DEFUSED/BOOM on startup
"inferred"false true = "exploded" assumed (no GSI event 2.5 s after reaching 0)
"gsi_connected"true A GSI packet arrived in the last 30 s
"map""de_mirage" Current map name from CS2
"version""1.0.0" Backend version string

Compatibility

The plugin only needs status and time_remaining. It also accepts state, remaining, time_left, or countdown — so an existing script with different field names usually still works.

⚠️ CORS: Your backend must send Access-Control-Allow-Origin: * on /state. Without it the Ulanzi Studio WebView blocks requests and the key shows OFFLINE.
